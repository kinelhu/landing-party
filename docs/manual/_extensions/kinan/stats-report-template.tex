% HEADER. Same override/hide grammar as the footer below, so the two halves of the
% page furniture are configured the same way. All three slots are EMPTY by default:
% the header was empty before this existed and no document should change without
% asking. `running-section: true` is the convenience case — the current section
% name, which is the only header content that earns its space in a long report
% (the document's identity is already in the footer, on every page).
% -----------------------------------------------------------------------------
$if(running-section)$
% The running name goes through LaTeX's MARK register, not a global macro. This matters, and the
% distinction is between the two marks and not between marks and macros:
%   \leftmark  is the LAST mark on the page. Reading the name back through it, or holding it in a
%              \gdef read at shipout, gives the same wrong answer -- a heading that begins in the
%              last inch of a page names the WHOLE page, including the inch of the previous
%              heading's text above it. sarcobs read "Three functional trajectories" across a page
%              whose top half was the Results section opening and its Cohort subsection, and whose
%              named heading began 45 percent of the way down.
%   \rightmark is the FIRST mark on the page, which is the semantics a running head wants: a page
%              is named by what it starts as. That asymmetry is what the two marks exist for.
% With no mark on a page at all, \rightmark carries the previous page's last mark forward, so a
% heading that spans several pages keeps its name on all of them.
%
% Why the filter below: tables here render as tabularray `longtabs`, and its
% continuation caption also drives \sectionmark. Without the guard a mark-based header
% sticks on "(Continued)" for every page a long table spans, which in a stats report is
% most of them. Rejecting any title containing "Continued" is crude, but it is the only
% signal available: nothing else distinguishes tabularray's call from a real section's.
% A section legitimately named "... Continued" would be skipped; that is acceptable.
%
% titlesec's \titleformat before-code was tried first and is not usable here — #1 is
% only bound in shapes that typeset the title themselves, not in the default `hang`.
%
% HOW DEEP. `running-section-depth` (default 1) sets the deepest heading level that updates the
% name: 1 = \section only, 2 = also \subsection, 3 = also \subsubsection. All levels write the SAME
% mark, so this is not a hierarchy -- a page carries the name of whichever level marked it first,
% and a subsection's parent is not shown alongside it.
%
% Depth 1 is right when the sections ARE the document's divisions, which is the usual case and why
% it is the default. Reach for 2 only when they are not: sarcobs has one "Results" section spanning
% 20 of its 30 pages, so a depth-1 head read "Results" on two thirds of the document.
%
% The comparison is done in TeX because pandoc's template language has no arithmetic: its
% conditional tests truthiness and nothing else, so a numeric option cannot be branched on at
% template level.
%
% The SPACES around the conditional below are load-bearing, and this comment cannot show you why,
% because pandoc parses THIS FILE as a template and a dollar sign in a comment is a directive. Two
% consequences, both met while writing these four lines:
%   * writing the conditional's closing delimiter immediately against the variable's opening one
%     produces a doubled dollar, which is pandoc's escape for a literal dollar. The interpolation
%     then never parses, and the error is reported at the END of the file.
%   * the brace form of interpolation is not the way out: it takes a variable, not a directive.
% A space between them is. TeX skips spaces before a number, so the count reads its digit either
% way. See conventions/report-building.md 2b, which records the same trap for a different reason.
\usepackage{xstring}
\newcount\gRunHeadDepth
\gRunHeadDepth=$if(running-section-depth)$ $running-section-depth$ $else$ 1 $endif$\relax
% EVERY level is defined here, including the ones the depth excludes, and that is the whole point.
% LaTeX's own \subsectionmark already calls \markright: while the head read a private macro only
% \sectionmark wrote, subsections were invisible whatever the stock definition did. Reading
% \rightmark instead means the stock definitions are suddenly live, so a depth that only ADDS
% redefinitions does not bound anything -- setting depth 1 left subsections marking through LaTeX's
% own hook. Found by rendering 2026-08-05-clad-reporting-audit, which sets no depth and whose head
% changed on 30 of its 49 pages. Levels above the depth are silenced explicitly.
\newcommand{\gSetRunHead}[1]{\IfSubStr{#1}{Continued}{}{\markright{#1}}}
\renewcommand{\sectionmark}[1]{\gSetRunHead{#1}}
\ifnum\gRunHeadDepth>1
  \renewcommand{\subsectionmark}[1]{\gSetRunHead{#1}}
\else
  \renewcommand{\subsectionmark}[1]{}
\fi
\ifnum\gRunHeadDepth>2
  \def\subsubsectionmark#1{\gSetRunHead{#1}}
\else
  \def\subsubsectionmark#1{}
\fi
% fancyhdr warns and misplaces the rule if \headheight is left at the article default
% of 12pt once anything is actually IN the header. Set once, here, rather than leaving
% every document to answer the warning itself.
% Manual: 15pt (fancyhdr asked for 14.8 with the running head in Monaspace Neon Light).
\setlength{\headheight}{15pt}
\addtolength{\topmargin}{-3pt}
$endif$
